PowerModeManager 다운로드 사용 방법 보기

PowerModeManager 1.0.0 (Build 8)을 Apple Silicon Mac의 macOS 15 이상에서 사용할 수 있습니다. 설치 파일은 서명·공증되었으며 Gatekeeper 검증을 통과했습니다.

Apple Silicon · arm64 macOS 15 이상

두 가지 모드

필요할 때는 계속 켜두고, 작업이 끝나면 되돌리세요.

개별 `pmset` 값을 외우지 않아도 되도록, macOS가 현재 Mac과 전원에서 지원하는 설정을 두 프로파일로 묶었습니다.

01

서버 모드

파일 서버나 빌드 작업처럼 Mac이 계속 작동해야 할 때 시스템 잠자기를 끄도록 설계했습니다. 디스플레이는 잠들 수 있습니다. 실제 적용되는 설정은 Mac과 전원 상태에 따라 다릅니다.

02

일반 모드

Mac을 계속 사용할 필요가 없을 때 앱의 평소 잠자기 프로파일로 돌아갑니다. 어느 모드든 적용 전에 바뀌는 값을 확인할 수 있습니다.

확인과 복원

적용하기 전에 어떤 설정이 바뀌는지 확인하세요.

전원 설정은 잠자기, 발열, 배터리 사용에 영향을 줍니다. 앱은 변경 내용을 보여주고 되돌릴 방법을 제공합니다.

먼저 미리 보기

모드 적용 전에 Mac에서 지원하는 프로파일 값과 현재 설정을 비교할 수 있습니다.

변경 승인

시스템 전원 설정을 바꿀 때 macOS가 관리자 승인을 요청합니다.

백업과 복원

앱은 모드 적용 전에 로컬 백업을 저장하고, 설정을 복원하는 기능을 제공합니다.

!

서버 모드는 필요한 동안만 사용하세요. MacBook에서는 전력 사용량과 배터리 소모가 늘 수 있습니다. 전원 어댑터를 연결하고 통풍이 잘되는 곳에서 사용한 뒤, 계속 켜둘 필요가 없어지면 일반 모드로 전환하세요. 이 앱은 배터리 충전량을 제한하거나 충전을 중단하지 않습니다.

시작하기

PowerModeManager 1.0.0을 다운로드하세요.

Build 8은 macOS Sequoia와 macOS 27.0.1에서 검증했습니다. Apple Silicon과 macOS 15 이상이 필요하며, 앱은 영어와 한국어를 지원합니다.

1.0.0 · Build 8

Apple Silicon 전용입니다. Mac16,8의 macOS 27.0.1 (Build 26A434)과 macOS Sequoia UTM 가상 머신에서 확인했습니다. 한국어 UI와 설정 적용·복원을 검증했습니다.

Homebrew로 설치

brew tap powermodeapp/tap
brew trust --cask powermodeapp/tap/powermodemanager
brew install --cask powermodemanager

DMG 열기

설치 파일을 내려받아 PowerModeManager를 응용 프로그램 폴더로 옮기세요.

변경 내용 확인

메뉴 막대 앱에서 바뀔 설정을 살펴보고, 원하는 변경만 승인하세요.

메뉴에서 종료

메인 창을 닫아도 메뉴 막대 앱은 계속 실행됩니다. 앱 메뉴에서 종료를 선택하세요.

업데이트 또는 제거

Homebrew로 설치했다면 brew upgrade --cask powermodemanager 명령으로 업데이트하세요. DMG 설치본은 업데이트를 직접 내려받아 설치하면 됩니다. 앱을 제거해도 백업과 선택적 기록은 Mac에 남습니다.

개인정보와 지원

앱 데이터는 Mac에 저장됩니다.

앱에는 원격 분석, 사용자 계정, 사용자 데이터 전송 기능이 없습니다. 이 정적 웹사이트도 분석 스크립트를 사용하지 않습니다.

로컬 파일

  • 설정 백업: ~/.powermode-backups
  • 선택적 모니터링 로그: ~/.powermode-monitor.log
  • 진단 보고서에 Mac 모델, 호스트 이름, 전력 설정이 포함될 수 있습니다.

앱을 삭제해도 이 파일들은 남을 수 있습니다. 공유 전에 보고서 내용을 확인하세요. 개인정보 안내 전문을 읽어보세요.

지원과 라이선스

발견된 문제점은 GitHub Issues에서 영어 또는 한국어로 제보할 수 있습니다. 앱 버전, macOS 버전, Mac 모델, 재현 절차를 적어주세요. 원본 진단 파일은 공유 전에 민감한 정보를 확인하고 지우세요.

보안 취약점은 비공개 제보를 이용하세요. 앱은 무료이며, MIT 라이선스에 따라 재배포하거나 판매할 수 있습니다.

사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 호스팅 과정에서 사이트 접속 정보를 처리할 수 있으며, 이는 Mac에 로컬로 저장되는 앱 데이터와 별개입니다.
